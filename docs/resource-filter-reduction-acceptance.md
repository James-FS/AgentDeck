# 资源库筛选精简验收记录

日期：2026-10-24。按 [资源库筛选精简实施方案](resource-filter-reduction-plan.md) 在含前序阶段未提交成果的工作区上增量完成 A → B → C；未提交、未推送 Git，未删除磁盘资源，未修改真实用户客户端配置。

## 实际行为

- **A（去除冗余运行时筛选）**：常驻筛选下拉从 8 个减为 4 个——关联客户端、项目范围（含“包含全局资源”条件复选框）、资源来源、配置状态。配置/使用范围（scopeFilter）、所属 Agent（ownerAgentFilter）、配置或文件来源（originFilter）、资源归类（categoryFilter）从运行时匹配路径整体退出：`matchesRecord`、独立发现匹配 `findingMatchesRecord`、隐藏搜索命中、`recordFiltersActive` 和清除逻辑均不再读取它们；活动条件标签不再生成这四类。四个旧状态字段按方案保留为中性值并参与 `clearFilters` 重置（`[]` / `'all'`），不存在用户无法清除的隐藏条件。分类证据逻辑（classification.ts、详情展示、resource-entities/resource-visibility）未改动；scope、agent 归属、origin、classification 数据仅在详情与可用性中解释。显式选择“Agent 内置”来源自动开启内置显示的行为保留。
- **B（压缩工具栏）**：工具栏两行布局——第一行类型页签 + 搜索 + “只看收藏” + “已保存视图”菜单；第二行四个筛选 + “显示选项”菜单，窄窗口自然换行（工具条不内部折行，整体作为换行单元，1366×768 无横向滚动）。“已保存视图”为一个紧凑菜单：顶部“保存当前视图”，条目点击应用并标“（当前）”，每条带命名删除按钮；无视图时显示空状态；键盘可聚焦打开（role="menu"）。保存的新视图旧契约字段写中性值（scope=[]、owner=[]、category=[]、origin='all'）。显示策略整行取消，改为“显示选项”两项菜单，按钮旁短标记（如“显示选项 · 内置”）表达已开启内容，菜单内显示隐藏数量（注明两类可能重叠）；隐藏搜索命中、收藏被隐藏、独立来源排除等针对性提示与显式显示动作保留。资源表上方常驻实体/加载说明移入标题旁“资源说明”入口（含聚合与加载未验证的简短边界）；搜索进度、预算、失败与“继续搜索后续资源”保留。“清除全部”改名“清除筛选”，为唯一清除入口；清除不影响显示偏好与可用性表单。
- **旧命名筛选兼容**：转换逻辑提取为纯函数（`ui-store.ts` 中 `savedFilterScope` / `legacyScopeToProjectScope` / `droppedLegacyConditions`），页面不重复实现。应用旧视图时：可支持的客户端、项目、类型、搜索、来源、配置状态、收藏与显示偏好照常应用；旧 scope 条件仅在“只有 user-global 且无具体项目”时等价转换为“仅全局”；其余 scope 组合、所属 Agent、资源归类、origin 不再执行，并一次性提示“此视图含已取消的筛选条件（使用范围、所属 Agent、来源类型……），已应用其余条件，可重新保存。”不静默扩大结果范围；读取与应用不自动覆盖或删除旧记录，只有显式保存写新版条件，删除仍需用户操作。手动调整条件会清除“（当前）”标记（保存/应用瞬间除外），视图不会被静默改写。

## 已知限制

1. **旧条件不再有任何筛选效果**：应用含技术条件的旧视图会得到比保存时更大的结果集（提示中明确说明）。这是方案选择的语义，不做静默保留或隐藏执行。
2. **“已保存视图（当前）”标记只跟踪保存时的条件**：应用后手动调整会清除标记，但视图列表不做 diff 提示“已偏离”。
3. **scope 条件的等价转换仅覆盖“仅 user-global、无项目”一种组合**：`['user-global']` + 具体项目、多值范围、项目子目录范围均按不可转换处理并提示；不做近似映射。
4. **分类匹配函数 `matchesClassification` 保留**：它不再被筛选运行时调用，仅供既有分类单元测试与后续复用；详情与可用性检查未使用它。
5. **资源说明入口为文字按钮 + 弹出面板**：面板内容是简短两段说明，不承载逐类诊断解释；技术证据（分类依据、安装证据、完整配置键等）仍以资源详情为准。
6. **真实客户端 opt-in 验收未启用**（`AGENTDECK_VERIFY_REAL_CLIENTS` / `AGENTDECK_VERIFY_NATIVE_CODEX` 保持关闭）；本轮未执行真实 Skill、MCP 或版本命令。
