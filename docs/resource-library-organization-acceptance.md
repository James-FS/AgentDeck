## 完成范围

- **A（显示策略与来源证据）**：新增纯判断模块 `resource-visibility.ts`——内置判定只认适配器验证的 `sourceKind: 'builtin'`（含插件子资源沿父链继承），配置关联判定基于 `origin: 'configuration'`、`configurationSourcePath`、`configurationKey`、`configurationEnabled` 与适配器安装登记证据，纯缓存判定要求缓存来源且无任何关联；明确禁用的配置仍算关联，不从 `enabled` 反推安装。偏好契约新增 `display: { showBuiltin, showCacheOnly }`（旧数据默认双关），服务端 GET 迁移旧 savedFilters 字段；`clearFilters` 不重置两个开关；显式选择“Agent 内置”来源自动开启内置开关，取消来源条件不自动关闭。
- **B（统一实体与身份聚合）**：新增纯派生模块 `resource-entities.ts`，替换原 `resource-tree.ts` 的三类分组：Skill 按物理路径身份聚合（统一“Skill 目录”与“SKILL.md 文件”口径，Windows 盘符路径大小写不敏感；旧索引缺少物理身份的保持独立并提示重扫），插件按实例/项目/插件身份聚合（未验证身份不合并），MCP 按服务入口证据聚合（插件附带组件保持独立实体并标注“来自某插件”），公共 `.agents` 资源以标志保留默认启用约定。独立发现与绑定纳入同一管线：同一物理 Skill 聚合为一行并保留全部关联记录，独立入口不能绕过可靠内置隐藏；同名不同目录保留副本并标注“同名副本”；发现内容哈希一致标注“说明文件相同”但不合并。实体展示键由物理/逻辑身份派生，与绑定顺序无关。
- **C（表格、详情、操作与计数）**：资源库主表精简为五列（资源 / 来源 / 关联 Agent·项目 / 状态 / 操作），移除缓存版本行、配置记录行和展开层级；名称统一打开详情——Skill 打开阅读详情并附“同一资源的其他关联记录”，插件 / MCP 打开新的实体详情（逐条关联记录含配置文件、配置键、版本、分类依据、安装证据与各自开关）。唯一控制目标（含共享同一原生开关地址的配置与缓存副本）保留直接开关；多个不同控制目标显示“管理绑定”并在详情逐条启停。统计卡、类型计数、隐藏数量、结果区与分页全部由同一实体集合派生；搜索隐藏命中提供“包含隐藏资源搜索”入口并同步开关；收藏按实体聚合并清理全部已知引用。
- **D（回归与文档）**：单元测试替换 `resource-tree.test.ts` 为 `resource-entities.test.ts`（16 项）并新增 `entity-favorites.test.ts`（2 项，覆盖非代表绑定收藏、取消清理与隐藏收藏可发现）；浏览器用例适配实体模型并新增 `resource-library.spec.ts`；README 已更新。

## 遗留限制

1. **Skill 物理身份基于路径归一化**：绑定的 `classification.sourceIdentity` 是服务端哈希，前端不可逆。聚合使用 `sourcePath` / 发现实际路径归一化（Windows 盘符路径忽略大小写）；若扫描根本身是链接或实际路径与逻辑路径不一致，同一物理 Skill 可能保守地显示为两行（不误合并），重扫后 `sourceIdentity` 存在时以路径为准。
2. **发现内容哈希仅在独立发现之间比较**：绑定记录没有 manifest 内容哈希，“说明文件相同”标注只覆盖发现入口之间的对比；跨绑定与发现的同内容判定仍需使用对比功能。
3. **同名副本计数为提示**：主表只显示“同名副本”徽标与数量，副本清单在详情说明中；未提供按名称的批量操作（按方案不自动合并、不按名称跳转）。
4. **隐藏数量可能重叠**：内置与仅缓存两类计数按实体分别统计，同一实体可能同时计入两类；文案已注明“两类可能重叠”，未做去重展示。
5. **状态汇总口径**：多绑定实体在全部绑定状态一致时显示统一状态（如“已启用”），数量摘要保留在悬停说明与不一致场景；公共 `.agents` 资源沿用“默认已启用”盘点约定，禁用记录数量在状态说明中给出。
6. **浏览器规模测量为单次采样**：1,000 条记录数值随环境波动，仅用于证明分页实体模型无数量级回退；未启用虚拟列表（50 行分页下无测量需求）。
7. **真实客户端 opt-in 验收未启用**（`AGENTDECK_VERIFY_REAL_CLIENTS` / `AGENTDECK_VERIFY_NATIVE_CODEX` 保持关闭）；原生 Codex 与真实客户端路径沿用既有夹具与 opt-in 覆盖，本轮未新增。
8. **实施过程中的环境干扰**：一次 playwright 运行曾因本机沙箱终止进程出现无输出退出（exit 127），经隔离复现确认与代码无关；最终完整 e2e 在禁用沙箱的普通终端中全部通过。
