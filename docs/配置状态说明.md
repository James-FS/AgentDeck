# 配置状态说明

更新：2026-10-04。按用户最新决定，Skill、MCP、插件统一显示三个状态，并支持“配置状态”多选筛选。

| 状态 | 判定规则 |
| --- | --- |
| 已启用 | 已识别的配置开关允许使用；或位于该 Agent 已登记资源目录，按盘点规则视为可读取，没有明确禁用记录时默认启用；未关联配置的插件缓存及其组件除外。 |
| 已禁用 | 原生配置明确禁用，包括 enable: false、enabled: false、disabled: true、插件禁用或父插件禁用等各客户端已有格式。 |
| 未确定 | 读取归属缺少证据、配置值无效或冲突、插件身份冲突、父绑定缺失等。字体为灰色。 |

这是资源盘点的静态默认规则，不是客户端运行探测；已启用不证明当前会话加载、MCP 连接成功或实际调用。只扫描既有 Agent 入口与明确登记项目，不因新规则全盘寻找项目或执行资源。公共 .agents 来源不会变成 Agent 专属资源；按用户最新约定，用户全局公共绑定没有明确禁用时默认已启用，配置解析异常也不改变这条展示缺省规则。明确 false 只禁用对应 Agent，公共资源行仍已启用。

扫描器统一生成 Binding.enabled 与 configurationStateReason。独立开关、父插件和 Claude 可见性等原始证据继续保存，用于详情说明，但不再产生额外状态标签。没有 enable 字段的有效 Codex 插件配置及有效 ZCode 路径记录按缺省启用；非布尔值与配置冲突保持未确定。例外：插件缓存及附带 Skill/MCP 未关联启用配置时保持未确定。预置、残留或安装缓存不等于客户端读取入口或启用登记；不能套用目录缺省启用规则。实际使用版本仍未确定。

列表、详情统一用“已启用 / 已禁用 / 未确定”。筛选支持多选、条件标签、逐项移除和清除全部，并与类型、Agent、范围、来源和搜索组合。插件作为匹配组件的父上下文保留，分组汇总状态可能与匹配子组件不同；展开可查看真正匹配的记录。不会合并后端绑定或改变写入授权、预览、备份、恢复、版本和只读边界。

更新后重新构建、重启 AgentDeck、刷新网页并重新扫描；旧索引里的未知值不会仅由前端猜测转换。真实客户端配置始终只读。

ZCode 路径开关来自 ~/.zcode/cli/config.json 的 skills[SKILL.md 完整路径].enable；关闭写入 false，开启通常删除覆盖。Codex 路径覆盖、Claude 可见性和 DSH 静态来源的解析见 [Skill 目录与开关核对](./Skill目录与开关核对.md)。审计 hash、日志、使用次数和安装锁文件不作为明确开关。
