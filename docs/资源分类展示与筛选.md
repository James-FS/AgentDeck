## 当前分类与证据规则

上一轮把“资源归类”和“使用范围”合为一项，导致未配置缓存全部显示范围未知，用户无法分清其存放归属。现在服务端契约分别返回 `classification.category`、`location` 与原有 `scope`，网页不从路径猜标签：

| 资源归类 | 依据与含义 |
| --- | --- |
| 用户全局来源 | 明确公共入口，无 Agent 所属；发现适配器另列，不证明所有 Agent 都已使用 |
| 项目公共来源 | 已登记项目的 `.agents/skills`、公共 `skills` 入口；无 Agent 所属，保留独立发现绑定 |
| Agent 全局资源 · Agent 名称 | 来源位于该 Agent 已登记配置根/缓存，或由适配器识别为该 Agent 用户配置；包含配置资源与未配置资源库内容 |
| Agent 项目资源 · Agent 名称 | 明确登记项目的对应 Agent 配置/资源入口，或项目配置精确引用的插件组件 |
| 归类待确定 | 缺少归类证据；旧索引需重启后台并重新扫描，不从旧字段自动推断 |

**资源归类不等于内容专用，也不等于已经安装或生效。**详情另外显示实际存放根、来源文件、配置/使用范围及安装登记证据。项目插件的原文可以存放在 Agent 全局缓存，而该项目使用绑定归为 Agent 项目资源；两者同时呈现。

项目插件按完整身份关联经过 manifest 名称校验的缓存，保留每个版本的独立 Skill/MCP 子绑定。父插件停用可确定子项配置停用；其他状态保持未知，不把全局配置开关或缓存版本当作项目实际使用版本。来源原文只读，全部派生绑定不可写。

Codex `.codex-remote-plugin-install.json` 的受限静态结构（schema_version=1、合法字符串 remote_plugin_id）作为包级安装登记旁证，原字段不返回网页；记录没有 scope/选用版本时不提升使用范围，不推断当前启用版本。Claude 安装登记的 user/project 范围、身份与版本关联证据继续保留，项目登记仍仅限明确登记的项目。

重新扫描已登记实例、发现并扫描操作现在同步刷新已登记项目；API 用 `scanRegisteredProjects` 显式请求，不寻找新项目。选定项目仍只刷新该项目。旧索引没有新增分类时显示重新扫描提示，不在浏览器猜分类。

## 历史验收记录（2026-10-03；旧字段与界面已被当前规则替代）

已有能力：四适配器有限只读扫描、明确登记项目扫描、稳定绑定身份、插件父子关系、配置路径/键、缓存状态、分组 Skill 的磁盘发现标记。原缺口：MCP/插件沿用 `native` 原生控制范围，网页禁用范围筛选；非 Skill 默认 `agent-specific` 混淆安装归属与内容适用性；缺少统一分类证据。

新增公共 `Binding.classification`，由适配器生成，包含盘点范围、Agent、配置/发现关系、项目名称与根目录、分类依据及证据路径。旧 `scope` 保留给原生控制与兼容案例匹配，不能据其 `native` 值推断盘点范围。旧索引没有新字段时范围/归属明确未知，重新扫描补齐。

列表与详情显示“用户全局 · Codex”“项目级 · Claude Code”等组合，项目名称、实际来源路径、分类依据和关联配置文件分开呈现。三类资源统一按作用范围与所属 Agent 筛选；所属 Agent 选项另含共享来源及未知。可与类型、来源、实例、项目及文字搜索组合。项目选择沿用“该项目与用户来源”视图；仅看项目资源时再选择项目级范围。

| 证据 | 分类规则与限制 |
| --- | --- |
| 用户配置层、适配器识别的用户 Skill 根 | 用户全局，仅表示不限定项目；不能证明所有 Agent 共用 |
| 明确登记项目中对应适配器的配置或资源根 | 项目级，包含登记项目名称与根；不会全盘寻找项目 |
| Claude `installed_plugins.json` 明确的 user 记录，身份/版本/缓存路径精确关联 | 缓存和子组件可显示用户全局，安装记录是证据；缺少 scope 且无用户配置关联则未知 |
| 缓存或原生插件目录、未关联配置 | 范围未知、仅磁盘发现；Agent 表示扫描来源归属，不能证明已安装/加载 |
| 插件子项 | 继承父绑定的盘点分类，保留独立子项身份与来源路径 |
| 同一实际来源路径、同类资源、同一原生键在多个 Agent 索引中出现 | 共享来源；列明所有已知 Agent 与绑定。同名、同内容副本、`.agents` 目录名称都不单独证明共享 |
| 目录分组或项目根中的 Skill | 不推断子目录生效语义；当前没有经确认的项目子目录级分类输出，筛选选项保留 |
| 安装在某个 Agent 下 | 所属 Agent 与内容适用性分开，三类资源内容兼容均未判断；不因目录位置声明专用或通用 |

共享索引在服务端读取 catalog 时由扫描证据构建，保留每个实例/项目绑定；单实例刷新后仍可关联已保留的其他项目绑定。证据仅代表已扫描索引，不证明当前会话使用，无法发现未扫描位置的共享者。项目资源不因同名合并；多个 Agent 指向同一资源也不合并绑定。
