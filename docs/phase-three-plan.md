# 第三阶段：日常效率（Sol 实施方案）

## 工作流与现状

遵循根目录 AGENTS.md：Sol 分析并确定方案，一次性委派一个 luna-implementer（gpt-6-luna / high）；Luna 独立实现、调试、自检；Sol 验收关键差异与验证证据。普通问题汇总为一轮返修，Sol 不并行修改实现。

前两阶段已有：客户端绑定与独立 Skill 来源、受限扫描、物理路径证据、详情与安全预览、分页搜索、可用性推测、SQLite 元数据及 SSE。本阶段复用这些能力，不改客户端配置写入权限，不启动 Skill、MCP 或插件。

## 范围与用户可见行为

1. **增量重扫**：自定义 Skill 来源重扫继续有界遍历，以发现新增与删除；未变化 manifest 可复用解析结果，变化文件重新读取。缓存键包含实际路径、文件身份/大小/修改时间和扫描选项；实时重新检查路径与链接边界。支持强制完整重扫，展示实际复用/读取数量。缓存有界、按来源失效，不能只是将原来的全量扫描改名。
2. **目录监听**：对已登记的自定义 Skill 来源提供默认关闭、可持久化的开关。事件合并与防抖，同一来源串行且扫描期间发生变化后再检查一次；只重扫该来源，沿用扫描上限与链接规则。通过已有 SSE 刷新界面。移除来源/关闭服务后释放监听与计时器，错误/不支持/根路径变化均明确显示，避免静默失效、重复监听和扫描风暴。客户端配置的自动监听不在本次范围，继续使用已有手动重扫。
3. **收藏与保存筛选**：客户端资源绑定与独立 Skill 均可收藏并筛选。可命名保存、应用、删除资源筛选（含类型、搜索及现有筛选项和实例/项目上下文）。存入本机应用数据库，刷新和重启后保留；失效引用清晰标记，不能关联到另一资源。仅保存有限、经过契约校验的偏好。
4. **复制路径与打开目录**：资源列表/详情或来源提供复制路径；浏览器剪贴板不可用时给出可手动复制的文本。打开目录为显式用户操作，通过有会话/CSRF 保护的接口；请求只接受已登记资源引用，不接收任意文件系统路径或 shell 命令。Skill 使用第二阶段物理根校验；配置型、插件、MCP 只打开可信来源所在目录，不运行资源或远程链接。启动目录打开器可注入测试替身，Windows 隐藏辅助窗口、将路径作为数据传递。
5. **重复资源与对比**：从已发现 Skill 中选择两个，区分同一物理来源、同名不同来源、manifest 内容一致/不同；提供有界的摘要与正文对比，保留绑定独立状态。不能仅凭名称认定重复，也不能将 manifest 一致说成整个包一致。不读取任意支持文件正文或越界路径。
6. **扫描变化列表**：自定义来源重扫展示新增、移除、修改；客户端手动扫描展示绑定新增、移除、配置状态变化。稳定身份比较，忽略扫描时间变化，Skill 正文变化需要内容摘要，不能仅比较名称。首次扫描标注建立基线；扫描失败、部分/截断时不把未覆盖条目误报为删除。持久化有界的最近结果与时间，不保存完整敏感配置；监听扫描也更新变化列表。

## 验收标准

- 同一来源第二次扫描有真实复用；新增/修改/删除后索引正确；强制重扫与增量结果一致；时间戳变化不产生虚假业务变化；链接替换不能绕过校验。缓存不跨不兼容选项或来源污染。
- 开启监听后，隔离目录新增/修改/删除会在合理超时内更新目录和变化记录；连续写入被合并、同一来源无并发覆盖；关闭/移除/重启/根路径替换有明确结果且不泄漏句柄。使用可注入调度器做稳定单测，并至少有一次真实文件监听集成验证。
- 收藏、保存筛选经过页面刷新与服务重启仍可用；收藏筛选同时覆盖绑定与独立发现；清除/删除行为可验证。
- 复制路径成功或给出明确回退；打开目录只触发注入的 opener，未认证、缺 CSRF、伪造引用、越界 junction、任意路径和命令输入被拒绝；不在测试中打开真实资源管理器。
- 相同名称但不同内容、相同 manifest 的不同副本、同一物理来源均能准确解释；越界/缺失/超限仍保持可诊断，不绕过详情读取边界。
- 变化列表覆盖新增、移除、正文修改、配置状态变化、无变化、初次基线、部分失败，且重启后保留最近结果；有条目上限与截断说明。
- `pnpm typecheck`、`pnpm lint`、针对性测试、完整 `pnpm test`、`pnpm build`、最新构建上的完整 `pnpm test:e2e` 通过。真实客户端 opt-in 测试保持按条件跳过。只使用隔离夹具，保留现有权限、启停、恢复、扫描边界与第二阶段回归。

## 约束

仅一个 Luna 独立执行，不新增无关依赖，不提交 Git、不改写用户新增的 AGENTS.md/.codex 工作流文件。平台监听若不支持需显式显示并提供手动扫描，不假装已开启。偏好和有界历史使用应用数据目录；扫描缓存可以是服务生命周期内的有界缓存，冷启动重建需说明。所有报告区分文件盘点和客户端实际加载。
