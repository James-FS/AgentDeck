# 公共全局资源去重展示

更新：2026-10-04。用户 .agents 公共目录中同一实际来源在资源表格只显示一条，类型统计也按公共实际来源去重；后端独立绑定继续保存。

合并需要扫描器的 sourceIdentity、明确用户全局公共分类、无 Agent 专属归属、.agents 入口证据和相同资源类型。只按真实来源合并，不按名称合并。不同物理副本、项目公共资源、未知来源和插件版本分组不混合。选择某个实例时只汇总该实例范围内的绑定。

列表标注“公共资源”，并显示“有禁用记录：Agent 名称”或“未发现明确禁用记录”。前者表示存在该 Agent 的禁用绑定，不代表所有同类客户端实例均禁用；详情逐实例显示状态、依据、配置路径和键。最新展示约定：用户 .agents 的公共资源行固定显示已启用；各 Agent 绑定无明确禁用时默认已启用，明确禁用只影响对应绑定，不把整个公共资源标成禁用。按配置状态筛选时，任一发现绑定匹配就保留公共资源行，详情与汇总保留其他绑定供对照。

按用户最新要求，未标禁用的 Agent 默认视为启用，这是 AgentDeck 的盘点展示约定，不是原生客户端自动发现或实际调用的证明。未扫描的 Agent 不增加虚构绑定，只在说明中表达默认规则。Codex/ZCode 原生配置中的明确禁用继续保留；公共路径的重复覆盖中发现明确 false 时，禁用标注优先。本机 gpt-image-2-style-library 是同一实际目录的 Codex 与 ZCode 两条发现绑定，不是两份安装。

扫描器同时为公共绑定生成缺省状态与判定依据；本轮改变展示和统计；不写真实客户端文件，不执行资源，不增加控制能力，不修改原绑定身份。公共汇总行只读，后端原有操作校验保留。重启并重新扫描后使用；缺少物理身份的旧索引需重扫。配置、版本折叠与现有筛选仍保留。
