# 首轮适配器与 Codex 变更引擎边界

日期：2026-10-02。首轮扫描器只读固定配置根和已登记项目，不启动客户端、Skill、插件、MCP 服务或其他子进程。发现时只检查 PATH 中的可执行文件是否存在；不运行版本命令，因此 `version` 保持 `null`。自动发现实例始终只读。

四个适配器使用稳定路径与原生键生成实例/Binding 标识。扫描配置根及其直接子目录，目录项上限为 300；JSON/TOML 配置读取上限为 1 MiB，Skill `SKILL.md` 上限为 96 KiB，DSH 每个 profile 目录最多读取 40 个 patch 文件。扫描跳过符号链接和 Windows junction，不遍历整盘或已登记项目根以外的路径。用户级 Binding 在项目扫描时仍保持 `projectId: null`；项目资源另行登记。

| Agent | 用户配置与资源候选 | 已登记项目候选 |
|---|---|---|
| Codex | `CODEX_HOME` 或 `~/.codex`；读取 `config.toml`、`~/.agents/skills`、`<configRoot>/skills` 和 `<configRoot>/plugins` | `.agents/skills`、`.codex/skills` |
| Claude Code | `CLAUDE_CONFIG_DIR` 或 `~/.claude`；读取 `settings.json`、`skills`、`plugins`，以及默认配置根的父目录中的 `.claude.json` | `.claude/skills`、`.agents/skills`、`.claude/settings.json`、`.claude/settings.local.json`、`.mcp.json` |
| ZCode | `ZCODE_HOME` 或 `~/.zcode`；读取 `cli/config.json`、`skills`、`plugins` | `.zcode/cli/config.json`、`.zcode/skills`、`skills` |
| DeepSeek Harness | `DSH_HOME` 或 `~/.dsh`；读取 `skills` 和 `profiles/<profile>/*.{yml,yaml}` 静态 patch 行 | `.dsh/skills`、`.dsh/profiles` |

这些路径是当前扫描器实现的候选布局，不表示已经通过全部客户端版本验证。ZCode 项目级 `skills` 候选、DSH 项目级 `.dsh` 候选和不同 `CLAUDE_CONFIG_DIR` 下的用户状态路径尤其需要实机兼容记录。插件清单只读取上述直接插件目录内可定位的 JSON 元数据；插件激活语义和插件内 MCP 始终只读。

Skill 的范围来自候选目录，来源来自用户、项目或插件目录；适用客户端兼容性一律为 `unknown`，扫描不从 Skill 正文推断能力。运行时状态一律为 `unknown`。Claude 的 `skillOverrides` 仅静态映射现存同名非插件 Skill；没有对应文件时显示只读配置 Binding，并标明名字级覆盖可能影响多个资源。

Codex MCP 扫描只把顶层 `mcp_servers.<name>` 当作独立服务器。独立服务器缺少 `enabled` 时，按 Codex 默认值显示为启用；非布尔值显示为未知并只读。`plugins.<name>.mcp_servers.<name>` 作为插件子项呈现，父插件明确停用时子项也显示停用，插件 MCP 不进入写入引擎。其他客户端的缺失状态保持 `null`，不自行推断默认值。

DSH patch 按 YAML AST 静态读取根序列中的插件行。`!!js` 标签由固定解析器映射成惰性标记；扫描器不把文档转换为可执行对象，不解析或执行表达式。动态、别名或缺失的 `disabled` 保持未知；不支持的 YAML 根结构和语法错误保留诊断。

唯一开放的客户端变更是手动登记且明确 `writable: true` 的 Codex 实例中、语法可唯一定位的独立 MCP 表；隔离 demo 实例可在其专用 demo 根内使用相同链路。版本尚未实机验证，Binding 会标注 experimental。TOML 编辑仅替换目标表中单行布尔 `enabled`，缺失时在该表插入；语法通过 `@iarna/toml` 解析前后校验并把 CRLF 规范化为仅供解析的视图。原始文件按字节编辑，保留 BOM、CRLF/LF、注释和无关字段。重复表、inline table、非布尔 `enabled`、无法定位结构都拒绝。

预览 diff 只列出目标表的 `enabled` 变化，不显示配置原文或秘密。apply 检查计划期限、摘要、目标路径各段的 realpath/符号链接身份，并在目标目录用独占 AgentDeck lock 协调不同数据目录的写入。恢复只在当前摘要与 apply 后摘要、路径身份均吻合时生成。任意第三方编辑器不会参与 AgentDeck lock；引擎会在替换前再次读取摘要，但不能与所有外部写入者形成共同原子锁。

恢复快照和待应用计划私有字节包含配置原文，可能含凭据；它们只保存在 AgentDeck 数据目录，不进入 Binding、诊断、API 计划 diff 或 Operation 错误。POSIX 数据目录/文件使用 `0700`/`0600`。Windows 未由本包显式创建或验证仅当前用户 ACL；数据目录的 Windows ACL 继承与部署环境设置有关，不能称为加密或当前用户独占访问。
