## Skill 分类修订专项验收

- [ ] “项目级 + Agent专用 + 仓库提供”等组合可保存、筛选、展示，不互相覆盖。
- [ ] 用户全局按实例划分；同一Skill部署到另一个Agent后保留独立Binding和状态。
- [ ] 未部署库资源没有虚构生效范围；未知兼容性明确显示未验证。
- [ ] 插件/组织/账号同步来源显示来源链与管理限制，标签不能绕过原生能力。
- [ ] 不支持子目录/会话范围的版本不会出现可执行的相应开关。
- [ ] 内容或客户端版本变化后兼容证据过期，重新规划前不能复用旧报告。
- [ ] 编辑共享原文列出全部已知读取实例；独立副本修改不影响其他副本。
- [ ] 批量规则选中明确资源与目标范围，新增资源不会被旧组合隐式停用。
- [ ] 用户修改分类不写入Skill原文，不改变客户端有效范围或权限。
